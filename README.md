# Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a menu-driven Python program that provides three useful tools: a simple calculator, a to-do list, and a number guessing game.

The project demonstrates variables, user input, output, conditionals, loops, lists, functions, and f-strings.

## Tools Included

### 1. Simple Calculator
Performs addition, subtraction, multiplication, and division. It also handles invalid numbers and division by zero.

### 2. To-Do List
Allows users to add tasks, view their tasks, and remove tasks while the program runs.

### 3. Number Guessing Game
Challenges the user to guess a randomly generated number between 1 and 10 and provides hints.

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   python toolkit.py
   ```

5. Follow the menu instructions.

## Reflection

The hardest part of this project was organizing the tools so that the program returned to the main menu after each one finished. The bug that took the longest to fix was handling invalid user input without stopping the program. I learned how to use loops and conditionals to control the flow of a program. I also learned how lists can store information that changes while a program runs. Testing each tool helped me find mistakes and improve the user experience. I am proud that the final program is interactive and easy to use. If I had one more week, I would add a feature that saves to-do tasks to a file so they are still available after the program closes.
